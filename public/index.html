Phishing URL Detection

A character-level convolutional neural network that classifies a URL as phishing or legitimate. Deep Learning semester project.

Live demo

The model only looks at the characters of the URL. It never visits the website, so treat the result as a screening signal, not a guarantee. API: POST /api/predict with {"url": "..."} or GET /api/predict?url=....

Dataset & code details

ProblemBinary classification of URLs: legitimate (0) vs phishing (1)
DatasetBalanced phishing/legitimate URL dataset from Zenodo (balanced_urls.csv, 340,000 rows, source record). 339,723 rows remain after removing 277 duplicate URLs.
SplitStratified 80/10/10: 271,777 train, 33,973 validation, 33,973 test (no URL overlap between splits)
PreprocessingCharacter-level vectorization, vocabulary of 97 symbols learned from the training split only, sequences padded or truncated to 300 characters
ModelEmbedding (32) → Conv1D (64 filters, kernel 5) → Global max pooling → Dense (64) → Dropout (0.3) → Sigmoid. 17,633 parameters.
TrainingAdam (lr 0.001), binary cross-entropy, batch size 256, early stopping on validation loss (stopped after 6 epochs, best weights restored)
DeploymentWeights exported to NumPy arrays; inference runs on a Vercel Python function without TensorFlow (verified against the Keras model: max probability difference 1.6e-06)

Known limitations

The dataset's phishing and legitimate URLs may differ in style (for example scheme or length), so the model can learn dataset-specific patterns. Newer attack styles, URL shorteners and unusual legitimate URLs may be misclassified. Use it as one signal among others.
